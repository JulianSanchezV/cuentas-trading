# Cuentas del Trading

Página: https://juliansanchezv.github.io/cuentas-trading/

Todos los que tengan el enlace ven el resumen y el historial. Solo quien tenga la clave de administrador puede editar.

## Crear tu clave de administrador (solo tú)
1. En GitHub, toca tu foto → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Nombre: `cuentas-trading`. Ponle una fecha de vencimiento.
3. En "Repository access" elige **Only select repositories** y marca solo `cuentas-trading`.
4. En "Permissions → Repository permissions" busca **Contents** y ponlo en **Read and write**.
5. Toca **Generate token** y copia la clave (solo se muestra una vez).

## Entrar como administrador
1. Abre la página y toca **Administrar**, al final.
2. El repositorio debe decir `juliansanchezv/cuentas-trading` (da igual si está en mayúsculas o minúsculas). Pega la clave y toca **Entrar**.
3. Aparece el panel de administración. Cada cambio se guarda en GitHub y los demás lo ven al recargar.
4. En otro computador o celular tendrás que pegar la clave de nuevo.

## Importante
- No compartas la clave con nadie. Quien la tenga puede editar los datos.
- Si la pierdes o crees que alguien la vio, bórrala en GitHub y crea otra.
- El repositorio es público: cualquiera que lo encuentre puede ver nombres y montos.
- Los datos viven en `datos.json`. No lo edites a mano salvo que sepas lo que haces.
